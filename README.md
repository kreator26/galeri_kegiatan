# galeri_kegiatan
Galeri Kegiatan adalah ruang digital yang mengabadikan setiap momen berharga di sekolah. Dari kegiatan belajar mengajar, perlombaan, upacara, hingga berbagai program pendidikan, seluruh dokumentasi foto dan video tersimpan secara aman, rapi, dan mudah diakses sebagai sumber informasi serta arsip sekolah.
